---
title: "MQTT integration"
description: "Connect evcc to your MQTT broker to monitor state and control charging via pub/sub messaging."
---

evcc can publish its full state to an MQTT broker and accept control commands via subscribed setter topics. This lets you integrate evcc with any MQTT-capable system — home automation controllers, Node-RED flows, custom dashboards, and more.

## Configuration

Add the `mqtt` section to your `evcc.yaml`:

```yaml
mqtt:
  broker: localhost:1883
  topic: evcc        # root topic for publishing; set empty to disable
  user: myuser       # optional
  password: mypassword  # optional
```

<Note>
Set `topic` to an empty string to disable all MQTT publishing while keeping the broker connection for other uses.
</Note>

<ParamField body="broker" type="string" required>
  Hostname and port of your MQTT broker, e.g. `localhost:1883` or `192.168.1.10:1883`.
</ParamField>

<ParamField body="topic" type="string" default="evcc">
  Root topic prefix. All published topics are nested under this value. Set to empty to disable publishing.
</ParamField>

<ParamField body="user" type="string">
  MQTT broker username (if your broker requires authentication).
</ParamField>

<ParamField body="password" type="string">
  MQTT broker password (if your broker requires authentication).
</ParamField>

## Topic structure

### Read topics (evcc → broker)

evcc publishes retained messages continuously during operation. All topics are prefixed with the configured root topic (default `evcc`).

#### Site-level topics

| Topic | Description | Example value |
|---|---|---|
| `evcc/updated` | Unix timestamp of last update | `1712345678` |
| `evcc/site/gridPower` | Grid power in W (positive = import) | `1234` |
| `evcc/site/pvPower` | PV generation in W | `3500` |
| `evcc/site/homePower` | Home consumption in W | `850` |
| `evcc/site/batteryPower` | Battery charge/discharge in W | `-500` |
| `evcc/site/batterySoc` | Battery state of charge in % | `72` |
| `evcc/site/gridConfigured` | Whether a grid meter is configured | `true` |
| `evcc/site/pvConfigured` | Whether a PV meter is configured | `true` |
| `evcc/site/batteryConfigured` | Whether a battery is configured | `true` |
| `evcc/site/prioritySoc` | Battery priority SoC threshold | `20` |
| `evcc/site/bufferSoc` | Battery buffer SoC | `80` |
| `evcc/site/smartCostLimit` | Global smart cost limit | `0.25` |

#### Loadpoint topics

Loadpoints are indexed starting at `1`. Topics follow the pattern `evcc/loadpoints/{id}/{key}`.

| Topic | Description | Example value |
|---|---|---|
| `evcc/loadpoints` | Number of configured loadpoints | `2` |
| `evcc/loadpoints/1/mode` | Charge mode | `pv` |
| `evcc/loadpoints/1/enabled` | Whether charging is active | `true` |
| `evcc/loadpoints/1/charging` | Whether vehicle is currently charging | `true` |
| `evcc/loadpoints/1/chargePower` | Current charge power in W | `7400` |
| `evcc/loadpoints/1/chargedEnergy` | Energy charged in this session (kWh) | `12.5` |
| `evcc/loadpoints/1/chargeDuration` | Duration of current session in seconds | `3600` |
| `evcc/loadpoints/1/connected` | Whether a vehicle is connected | `true` |
| `evcc/loadpoints/1/vehicleSoc` | Vehicle state of charge in % | `65` |
| `evcc/loadpoints/1/limitSoc` | SoC charge limit in % | `80` |
| `evcc/loadpoints/1/limitEnergy` | Energy charge limit in kWh | `20` |
| `evcc/loadpoints/1/minCurrent` | Minimum charging current in A | `6` |
| `evcc/loadpoints/1/maxCurrent` | Maximum charging current in A | `16` |
| `evcc/loadpoints/1/phasesConfigured` | Configured phases (0=auto, 1, 3) | `3` |
| `evcc/loadpoints/1/phasesActive` | Actively used phases | `3` |
| `evcc/loadpoints/1/vehicleName` | Assigned vehicle name | `car1` |
| `evcc/loadpoints/1/smartCostLimit` | Per-loadpoint smart cost limit | `0.25` |

#### Vehicle topics

| Topic | Description | Example value |
|---|---|---|
| `evcc/vehicles` | Number of configured vehicles | `1` |

### Write topics (broker → evcc)

To send commands to evcc, publish to a topic ending in `/set`. evcc subscribes to these and applies the value immediately.

#### Site setters

| Topic | Type | Description |
|---|---|---|
| `evcc/site/bufferSoc/set` | float | Set battery buffer SoC |
| `evcc/site/bufferStartSoc/set` | float | Set battery buffer start SoC |
| `evcc/site/prioritySoc/set` | float | Set battery priority SoC |
| `evcc/site/batteryDischargeControl/set` | bool | Enable/disable discharge prevention |
| `evcc/site/residualPower/set` | float | Set grid residual power in W |
| `evcc/site/smartCostLimit/set` | float | Set smart cost limit for all loadpoints |
| `evcc/site/smartFeedInPriorityLimit/set` | float | Set feed-in priority limit for all loadpoints |
| `evcc/site/batteryGridChargeLimit/set` | float | Set battery grid charge limit |
| `evcc/site/batteryMode/set` | string | Override battery mode (`normal`, `hold`, `charge`) |

#### Loadpoint setters

Topics follow the pattern `evcc/loadpoints/{id}/{key}/set`.

| Topic | Type | Description |
|---|---|---|
| `evcc/loadpoints/1/mode/set` | string | Set charge mode (`off`, `now`, `minpv`, `pv`) |
| `evcc/loadpoints/1/limitSoc/set` | int | Set SoC limit (0–100) |
| `evcc/loadpoints/1/limitEnergy/set` | float | Set energy limit in kWh |
| `evcc/loadpoints/1/minCurrent/set` | float | Set minimum current in A |
| `evcc/loadpoints/1/maxCurrent/set` | float | Set maximum current in A |
| `evcc/loadpoints/1/phasesConfigured/set` | int | Set phases (0, 1, or 3) |
| `evcc/loadpoints/1/priority/set` | int | Set loadpoint priority |
| `evcc/loadpoints/1/smartCostLimit/set` | float | Set per-loadpoint smart cost limit |
| `evcc/loadpoints/1/batteryBoost/set` | bool | Enable/disable battery boost |
| `evcc/loadpoints/1/vehicle/set` | string | Assign vehicle by name (empty/`-` to unassign) |
| `evcc/loadpoints/1/enableThreshold/set` | float | PV enable power threshold in W |
| `evcc/loadpoints/1/disableThreshold/set` | float | PV disable power threshold in W |
| `evcc/loadpoints/1/enableDelay/set` | duration | PV enable delay (e.g. `1m`) |
| `evcc/loadpoints/1/disableDelay/set` | duration | PV disable delay (e.g. `3m`) |

#### Vehicle setters

Topics follow the pattern `evcc/vehicles/{name}/{key}/set`.

| Topic | Type | Description |
|---|---|---|
| `evcc/vehicles/car1/limitSoc/set` | int | Set vehicle SoC limit |
| `evcc/vehicles/car1/minSoc/set` | int | Set vehicle minimum SoC |

## Example messages

### Publish to set charge mode

```bash
mosquitto_pub -h localhost -t "evcc/loadpoints/1/mode/set" -m "pv"
```

### Set SoC limit to 80%

```bash
mosquitto_pub -h localhost -t "evcc/loadpoints/1/limitSoc/set" -m "80"
```

### Subscribe to all evcc topics

```bash
mosquitto_sub -h localhost -t "evcc/#" -v
```

### Subscribe to loadpoint 1 state only

```bash
mosquitto_sub -h localhost -t "evcc/loadpoints/1/#" -v
```

### Unassign vehicle from loadpoint

```bash
mosquitto_pub -h localhost -t "evcc/loadpoints/1/vehicle/set" -m "-"
```

<Tip>
evcc publishes all topics with the **retained** flag. New subscribers immediately receive the last known value for every topic without waiting for the next update cycle.
</Tip>

<Warning>
Publishing an invalid value to a setter topic (e.g. an out-of-range SoC or an unknown mode string) is silently ignored. Check evcc logs at the `mqtt` level if a setter does not appear to work.
</Warning>
