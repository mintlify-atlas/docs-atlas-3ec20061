---
title: "Quick start"
description: "Get evcc running and start your first solar charging session in minutes."
---

<Steps>
  <Step title="Install evcc">
    Choose your preferred installation method. Docker is the fastest way to get started:

    ```bash
    docker run -d \
      --name evcc \
      -p 7070:7070 \
      -v $(pwd)/evcc.yaml:/etc/evcc.yaml \
      evcc/evcc:latest
    ```

    For other methods, see the [Installation guide](/installation).
  </Step>

  <Step title="Run the configuration wizard">
    evcc includes an interactive configuration wizard that detects your devices and generates `evcc.yaml`:

    ```bash
    evcc configure
    ```

    The wizard walks you through:
    - Detecting energy meters (grid, PV, battery)
    - Adding your EV charger
    - Adding your vehicle(s)
    - Setting up tariffs

    When finished, it writes a ready-to-use `evcc.yaml` to the current directory.
  </Step>

  <Step title="Verify your configuration">
    Before starting, check your configuration for errors:

    ```bash
    evcc checkconfig
    ```

    This validates all device connections and reports any issues without starting the full server.
  </Step>

  <Step title="Start evcc">
    <Tabs>
      <Tab title="Direct">
        ```bash
        evcc
        ```
      </Tab>
      <Tab title="Docker">
        ```bash
        docker start evcc
        ```
      </Tab>
      <Tab title="systemd">
        ```bash
        sudo systemctl start evcc
        sudo systemctl enable evcc  # start on boot
        ```
      </Tab>
      <Tab title="Homebrew (macOS)">
        ```bash
        brew services start evcc
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Open the evcc UI">
    Navigate to [http://localhost:7070](http://localhost:7070) in your browser (or replace `localhost` with your server's hostname or IP).

    If mDNS is enabled on your network, you can also access evcc at [http://evcc.local:7070](http://evcc.local:7070).

    <Tip>
      The default hostname is `evcc`. You can change it in the `network.host` setting in `evcc.yaml`.
    </Tip>
  </Step>

  <Step title="Start charging">
    Once the UI loads, you'll see your loadpoints (charging stations). Connect your EV and select a charging mode:

    - **PV** — charge only when solar surplus is available
    - **Min+PV** — charge at minimum current always, boost with solar surplus
    - **Now** — charge as fast as possible
    - **Off** — disable charging

    Solar surplus charging starts automatically when enough PV power is available.
  </Step>
</Steps>

## Minimal evcc.yaml example

If you prefer to configure manually rather than using the wizard, here's a minimal working configuration:

```yaml evcc.yaml
network:
  host: evcc
  port: 7070

interval: 30s

meters:
  - name: grid
    type: template
    template: sdm630
    uri: 192.168.1.10:502

  - name: pv
    type: template
    template: fronius-symo
    uri: 192.168.1.20

chargers:
  - name: wallbox
    type: template
    template: go-e
    uri: 192.168.1.30

vehicles:
  - name: mycar
    type: template
    template: volkswagen
    user: me@example.com
    password: secret
    vin: WVWZZZ1KZAM000000
    capacity: 58

site:
  title: Home
  meters:
    grid: grid
    pv:
      - pv

loadpoints:
  - title: Garage
    charger: wallbox
    vehicle: mycar
    mode: pv

tariffs:
  currency: EUR
  grid:
    type: fixed
    price: 0.30
  feedin:
    type: fixed
    price: 0.08
```

<Note>
  Replace device templates, URIs, and credentials with your actual hardware. Use `evcc configure` to auto-detect supported devices.
</Note>
